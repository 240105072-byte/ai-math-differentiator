# Web-Based AI Math Differentiator

## Topic: Quadratic Equations
An interactive web application leveraging Artificial Intelligence to adapt a single core mathematical task (Quadratic Equations) into 3 distinct difficulty levels for differentiated learning.

## Features
- **Level 1 (Foundation):** Simplified context, step-by-step guided hints, simple integer solutions.
- **Level 2 (Standard):** Standard grade-level curriculum problems with discriminant formula hints.
- **Level 3 (Advanced):** Complex real-world application scenarios (projectile motion/optimization) with multi-step logic challenge.

## Tech Stack
- Frontend: HTML5, CSS3, JavaScript (ES6)
- AI Model Integration: OpenAI API (`gpt-4o-mini`)
- Deployment: Netlify
